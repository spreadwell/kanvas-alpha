# Kanvas (alpha)

Kanvas is a free Markdown notes app: your notes stay plain `.md` files in a
folder you choose, and the formatting gets out of the way while you write.

This page holds the alpha builds for Android. The app isn't in any store yet.

## Install

1. On your Android phone, open the [latest release](https://github.com/spreadwell/kanvas-alpha/releases/latest)
   and download the `.apk` file.
2. Open the download. Android will ask you to allow installs from your browser
   the first time.

## Updates

Kanvas checks this page when it opens. When a new version is out, a line
appears at the top of your note: tap **Update**. The first time, Android asks
you to allow installs from Kanvas.

## Alpha

Things change and things break. Keep a copy of notes you care about.
